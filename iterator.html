3.1

3.2

List に格納された要素数を取得する方法

List は可変長です。現在の要素数は size() で取り出し、 要素は get(i) で取得します。

  • size() はインスタンスメソッド
  • 配列の length と似た役割
  • for 文の条件式で使うと、配列と同じように平均を求められる

3.3

Iterator インタフェースと、それを使う理由

Iterator を使うと、データを持つ役割と、1 件ずつ取り出す役割を分けられます。 役割を分けると、main() に処理を詰め込みすぎない、オブジェクト指向らしい書き方になります。

📚
List データを保持する
🎯
Iterator 1 件ずつ取り出す
🧩
Set でも使える コレクション全般に応用できる
イメージ：List は「箱」、Iterator は「箱から順に取り出す手」です。 役割が分かれると、コードの見通しがよくなります。
3.4

List から Iterator のインスタンスを生成する方法

Iterator は new で直接作りません。 List などのコレクションが持つ iterator() メソッドを使って生成します。

  • コレクション API の仕事として Iterator を作る
  • 実装クラスを意識しなくてもよい
  • そのコレクション専用の Iterator が返ってくる

3.5

next メソッド

next() は、次の要素を返します。呼び出すたびに 1 件ずつ前へ進むので、 取り出したい値を変数に入れて使うことが多いです。

  • 戻り値は要素の型になる
  • 呼ぶと Iterator の位置が進む
  • 先に hasNext() で確認すると安全

3.6

hasNext メソッド

hasNext() は、まだ次の要素があるかどうかを真偽値で返します。 ループの継続条件に使うと、最後まで安全に取り出せます。

  • 戻り値は boolean
  • true の間だけ next() へ進む
  • Iterator を使った while 文の条件にぴったり合う

3.7

Iterator と while 文によるループ処理

コレクション API では、Iterator の hasNext() があるため、 while 文で 1 件ずつ処理できます。

  • 配列は主に for 文
  • Iterator は while 文と相性がよい
  • 要素数を先に数えなくても、最後まで順番に取り出せる

3.8

ループ処理内で要素を削除する

Iterator を使うと、ループの途中で要素を削除できます。削除は remove() で行い、 現在の要素を安全に取り除きます。

  • 削除したいときは Iterator.remove() を使う
  • next() の後で remove() を呼ぶ
  • ループ中に list.remove() を直接使うとトラブルの原因になりやすい

3.9

Enumeration インタフェース

Enumeration は Iterator と同じく、1 件ずつ要素を取り出すための古い仕組みです。 以前の Java では Vector と一緒によく使われましたが、現在はあまり使われません。

  • Iterator より歴史が古い
  • Vector とセットで見かけることがある
  • 今は Iterator を使うのが基本
