5.1〜5.2 Mapとハッシュテーブルの仕組み

Map（HashMap）がなぜ高速なのか、その秘密は「ハッシュテーブル」というデータ構造にあります。

ハッシュテーブルとは？
たとえば、100冊の本がある本棚から特定の本を探すとき、端から1冊ずつ見ていく（Listのやり方）のは時間がかかります。 ハッシュテーブルは、「本のタイトル（キー）」から「本棚の番号（ハッシュ値）」を一瞬で計算する仕組みです。計算した番号の場所へ直接手を伸ばすため、データが何万件あっても一瞬で取り出せるのです。

Hashtable クラス（参考コード）

        

        

          古いJavaで使われていたクラスです。現在はHashMapを使うのが一般的ですが、古い現場では必須の知識です。
        

        
import java.util.*;

class CollectionSample {
    public static void main(String[] args) {
        Hashtable<String, String> ht = new Hashtable<String, String>();

        ht.put("first_name", "taro");
        ht.put("last_name", "tanaka");
        ht.put("email", "taro@example.jp");

        // Enumerationを使用して取り出す
        Enumeration<String> e = ht.keys();

        while (e.hasMoreElements()) {
            String key = e.nextElement();
            String value = ht.get(key);
            System.out.println(key + ": " + value);
        }
    }
}

        

          講師の目：Hashtableは、複数のプログラムから同時にアクセスしても壊れない「スレッドセーフ」という特徴がありますが、その分少し重いという面もあります。
