<Java/> INTERFACE DRILL

interface 演習

初級 → 中級 → 上級の順に取り組みましょう。インターフェイスを実装したクラスを定義し、要求された実行結果を出力するプログラムを作ります。

STEP 01
初級穴埋めで implements と public の書き方を確認
STEP 02
中級インターフェイスを実装し、独自のフィールドとメソッドを追加
STEP 03
上級定数の利用と、複数クラスをインターフェイス型でまとめて扱う

確認ポイント

  • クラスでインターフェイスを実装するには implements を使う
  • インターフェイスのメソッドは自動的に public abstract になる
  • 実装するメソッドには必ず public を付ける
  • インターフェイスで定義されたすべての抽象メソッドを実装する
  • インターフェイスのフィールドは自動的に public static final（定数）になる
初級

問題1　穴埋め

目標implements の書き方と、実装メソッドに public が必要なことを理解する

次のインターフェイス Animal を実装した Cat クラスを完成させます。①〜⑤の入力欄に当てはまるコードを入力し、「答え合わせ」を押してください。

Main.java
interface Animal{
    void setName(String name);
    void setAge(int age);
    void show();
}

class Cat ① Animal{
    private String name;
    private int age;

    ② void setName(String name){
        this.name = name;
    }
    public void setAge(int age){
        ③
    }
    public void show(){
        System.out.println(name + "の年齢は" + age + "歳です。");
    }
}

public class Main{
    public static void main(String[] args){
        Cat c = ④;
        c.setName("タマ");
        c.setAge(2);
        ⑤
    }
}

要求されている実行結果

Terminal
タマの年齢は2歳です。
ヒント

② はアクセス修飾子です。インターフェイスのメソッドは自動的に public abstract になるため、実装するときに選べる修飾子は1つしかありません。

③ と ⑤ は1行の文なので、最後にセミコロン ; が必要です。

解答を見る
① implements
② public
③ this.age = age;
④ new Cat()
⑤ c.show();

問題2　クラスの定義

目標インターフェイスのメソッドをすべて実装し、さらに独自のフィールドとメソッドを追加できる

次のインターフェイス Book を元に、Textbook クラスを定義してください。

Book.java
interface Book{
    void setTitle(String title);
    void setPrice(int price);
    void setPages(int pages);
    void show();
}

さらに、Textbook クラスには、subject（科目）という文字列型のフィールドと、そのフィールドに値を代入するための setSubject() メソッドを設けてください。

main メソッドでは、書名「Java入門」、価格 2800、ページ数 320、科目「プログラミング」を設定して show() を呼び出してください。

要求されている実行結果

Terminal
Java入門の価格は2800円です。
Java入門のページ数は320ページです。
Java入門の科目はプログラミングです。
ヒント

インターフェイスのメソッドは4つあります。1つでも実装し忘れるとコンパイルエラーになります。

setSubject() はインターフェイスにはない、Textbook 独自のメソッドとして追加します。

解答例を見る
interface Book{
    void setTitle(String title);
    void setPrice(int price);
    void setPages(int pages);
    void show();
}

class Textbook implements Book{
    private String title;
    private int price;
    private int pages;
    private String subject;

    public void setTitle(String title){
        this.title = title;
    }
    public void setPrice(int price){
        this.price = price;
    }
    public void setPages(int pages){
        this.pages = pages;
    }
    public void setSubject(String subject){
        this.subject = subject;
    }
    public void show(){
        System.out.println(title + "の価格は" + price + "円です。");
        System.out.println(title + "のページ数は" + pages + "ページです。");
        System.out.println(title + "の科目は" + subject + "です。");
    }
}

public class Main{
    public static void main(String[] args){
        Textbook t = new Textbook();
        t.setTitle("Java入門");
        t.setPrice(2800);
        t.setPages(320);
        t.setSubject("プログラミング");
        t.show();
    }
}

問題3　複数クラスの実装

目標インターフェイスの定数を利用し、複数の実装クラスをインターフェイス型の配列でまとめて扱える

次のインターフェイス Product を実装した、Food クラスと Drink クラスを定義してください。

Product.java
interface Product{
    double TAX = 0.1;
    void setName(String name);
    void setPrice(int price);
    void setStock(int stock);
    void show();
}

それぞれのクラスには、次の独自フィールドとメソッドを設けてください。

  • Food クラス：文字列型のフィールド expiry（賞味期限）と setExpiry() メソッド
  • Drink クラス：int 型のフィールド volume（容量）と setVolume() メソッド

show() では、定数 TAX を使って税込価格（小数点以下切り捨て）も表示してください。

main メソッドでは、次の2つの商品を作成し、Product 型の配列に格納してから、for 文で順に show() を呼び出してください。

  • Food：おにぎり、価格 150、在庫数 20、賞味期限「2026-12-31」
  • Drink：お茶、価格 120、在庫数 30、容量 500

要求されている実行結果

Terminal
おにぎりの価格は150円です。
おにぎりの税込価格は165円です。
おにぎりの在庫数は20個です。
おにぎりの賞味期限は2026-12-31です。
お茶の価格は120円です。
お茶の税込価格は132円です。
お茶の在庫数は30個です。
お茶の容量は500mlです。
ヒント

税込価格は (int)(price * (1 + TAX)) で求められます。

setExpiry() や setVolume() はインターフェイスにないメソッドなので、Product 型の変数からは呼び出せません。まず Food 型・Drink 型の変数で値を設定してから、配列に格納しましょう。

解答例を見る
interface Product{
    double TAX = 0.1;   // 自動的に public static final
    void setName(String name);
    void setPrice(int price);
    void setStock(int stock);
    void show();
}

class Food implements Product{
    private String name;
    private int price;
    private int stock;
    private String expiry;

    public void setName(String name){
        this.name = name;
    }
    public void setPrice(int price){
        this.price = price;
    }
    public void setStock(int stock){
        this.stock = stock;
    }
    public void setExpiry(String expiry){
        this.expiry = expiry;
    }
    public void show(){
        int taxIncluded = (int)(price * (1 + TAX));
        System.out.println(name + "の価格は" + price + "円です。");
        System.out.println(name + "の税込価格は" + taxIncluded + "円です。");
        System.out.println(name + "の在庫数は" + stock + "個です。");
        System.out.println(name + "の賞味期限は" + expiry + "です。");
    }
}

class Drink implements Product{
    private String name;
    private int price;
    private int stock;
    private int volume;

    public void setName(String name){
        this.name = name;
    }
    public void setPrice(int price){
        this.price = price;
    }
    public void setStock(int stock){
        this.stock = stock;
    }
    public void setVolume(int volume){
        this.volume = volume;
    }
    public void show(){
        int taxIncluded = (int)(price * (1 + TAX));
        System.out.println(name + "の価格は" + price + "円です。");
        System.out.println(name + "の税込価格は" + taxIncluded + "円です。");
        System.out.println(name + "の在庫数は" + stock + "個です。");
        System.out.println(name + "の容量は" + volume + "mlです。");
    }
}

public class Main{
    public static void main(String[] args){
        Food f = new Food();
        f.setName("おにぎり");
        f.setPrice(150);
        f.setStock(20);
        f.setExpiry("2026-12-31");

        Drink d = new Drink();
        d.setName("お茶");
        d.setPrice(120);
        d.setStock(30);
        d.setVolume(500);

        Product[] products = { f, d };
        for(int i = 0; i < products.length; i++){
            products[i].show();
        }
    }
}
