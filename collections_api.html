6. コレクション API のおさらいと補足

基本データ型からオブジェクトへの変換、および各コレクションの特性を整理します。

6.1

ラッパークラス

int や boolean といった基本データ型は、参照型と違い、オブジェクトとして扱えません。 そのため、基本データ型は List や Map の要素の型としては直接利用できません。

ラッパークラス（wrapper class）を使うことで、間接的に基本データ型の値を要素として持たせることができます。

基本データ型対応するラッパークラス
byteByte
shortShort
intInteger
longLong
floatFloat
doubleDouble
charCharacter
booleanBoolean
6.2

List インタフェース

順序を持つ、可変長のデータ管理

List は、通常の配列とほぼ同じで、ひと繋がりの箱のようなものです。箱に番号（インデックス）を振り、データを格納します。 配列は固定長ですが、List は要素の追加や削除を柔軟に行える メリットがあります。

List<String> list = new ArrayList<>(); // 要素の追加 list.add("東京"); list.add("大阪"); // インデックスを指定して取得・削除 String city = list.get(0); list.remove(0); System.out.println("残りの要素数: " + list.size());
6.3

Set インタフェース

重複を許さない要素の集まり

List が「〇番目に△△が格納されている」という概念であるのに対し、Set は ただの要素の集まり です。 同じ値の要素を2つ以上格納することはできません。

Set<Integer> set = new HashSet<>(); set.add(100); set.add(200); set.add(100); // 重複しているため、この追加は無視される System.out.println("要素数（2になるはず）: " + set.size());
6.4

Map インタフェース

キー（Key）と値（Value）のペア管理

Map は、「〇〇と書かれた場所に △△ が入っている」という概念です。 名前の書かれたロッカーのようなもので、キーと値をペアにして格納します。

Map<String, String> map = new HashMap<String, String>(); map.put("last_name", "taro"); map.put("first_name", "tanaka"); map.put("email", "taro@example.jp"); map.put("pref", "tokyo"); // キーを指定して値を取得 String email = map.get("email"); System.out.println("メールアドレス: " + email);
6.5

Iterator インタフェース

要素を1件ずつ取り出す共通の作法

List などのコレクションに格納した要素を 1 件ずつ取得してループ処理を行いたい際に便利なのが Iterator です。 コレクションからデータを効率よく取り出すための仕組みを提供します。

// リストからIteratorを取得 Iterator<String> it = list.iterator(); // 次の要素があるか確認しながらループ while(it.hasNext()) { String str = it.next(); // 1件取り出し System.out.println(str); }
