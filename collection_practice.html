Java基本文法3 ／ 練習問題

6. コレクション API 練習問題

List・Set・Map・Iterator を、実際にプログラムを書いて動かしながら確かめましょう。

使い方

  1. 各問題の「やること」を読み、エディタに import 文・クラス宣言・main メソッドも含めて、プログラム全体を 自分で入力します。クラス名は Main にしてください。
  2. ▶ 実行 ボタン（または Ctrl＋Enter）でコンパイル・実行します。コンパイルエラーもそのまま表示されます。
  3. 出力が「期待される出力」と一致すると 正解 と表示されます。

※ 実行にはインターネット接続が必要です（オンラインコンパイラ Wandbox を利用）。書いたコードはこのブラウザに自動保存されます。

問題 1

List インタフェース

果物リストを操作しよう

やること

  1. 必要なクラスを import する（List と ArrayList）
  2. Main という名前のクラスを宣言し、その中に main メソッドを書く
  3. 要素の型が String の List を ArrayList で作成する（変数名は list）
  4. list に "りんご"、"バナナ"、"みかん" をこの順で追加する
  5. インデックス 1 の要素を削除する
  6. 末尾に "ぶどう" を追加する
  7. 要素数・先頭の要素・最後の要素を、下の形式で出力する
期待される出力

      
ヒント

        import 文は import java.util.クラス名; の形で、使うクラスごとに1行ずつ書きます。クラス宣言は public class Main {、main メソッドは public static void main(String[] args) { です。{ と } の数をそろえましょう。

        追加は add()、削除は remove(インデックス)、取得は get(インデックス)、要素数は size()。

        インデックスは 0 から始まるので、最後の要素のインデックスは size() - 1 です。

問題 3
Map インタフェース

      
科目と点数をペアで管理しよう

      

        
やること

        
    
          
  1. 必要なクラスを import する（Map と HashMap）
    2. 
          
  2. Main という名前のクラスを宣言し、その中に main メソッドを書く
    3. 
          
  3. キーが String、値が Integer の Map を HashMap で作成する（変数名は scores）
    4. 
          
  4. "国語"→80、"数学"→65、"英語"→90 の3組を追加する
    5. 
          
  5. "数学" の点数を取り出して出力する
    6. 
          
  6. "数学" の点数を 75 に更新する
    7. 
          
  7. 更新後の数学の点数・科目数・"理科" というキーがあるかを出力する
    8. 
        

      

      
期待される出力

      
ヒント

        import 文は import java.util.クラス名; の形で、使うクラスごとに1行ずつ書きます。クラス宣言は public class Main {、main メソッドは public static void main(String[] args) { です。{ と } の数をそろえましょう。

問題 4
Iterator インタフェース

      
点数を1件ずつ取り出して集計しよう

      

        
やること

        
    
          
  1. 必要なクラスを import する（List、ArrayList、Iterator）
    2. 
          
  2. Main という名前のクラスを宣言し、その中に main メソッドを書く
    3. 
          
  3. 要素の型が Integer の List を ArrayList で作成し（変数名は scores）、72, 45, 90, 58, 66 をこの順で追加する
    4. 
          
  4. int 型の変数 total（合計）と passed（60点以上の人数）を作り、どちらも 0 で初期化する
    5. 
          
  5. scores から Iterator を取得する（変数名は it）
    6. 
          
  6. while 文と hasNext() / next() で1件ずつ取り出し、
            
      
              
    • その点数を「72点」のように出力する
      • 
              
    • total に足す
      • 
              
    • 60点以上なら passed を 1 増やす
      • 
            
    
          
    7. 
          
  7. ループのあとで、合計と60点以上の人数を出力する
    8. 
        

      

      
期待される出力

      
ヒント

        import 文は import java.util.クラス名; の形で、使うクラスごとに1行ずつ書きます。クラス宣言は public class Main {、main メソッドは public static void main(String[] args) { です。{ と } の数をそろえましょう。

        Iterator の型は要素の型に合わせて Iterator<Integer> にします。

        next() は呼ぶたびに次の要素へ進みます。1回のループで next() は1回だけ 呼び、取り出した値を変数に入れてから使いましょう。
